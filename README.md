# Zodiac Human

A Human Design web app: enter your birth data to see your bodygraph, type, strategy, authority, profile, centers, channels and gates — plus daily transits, relationship comparisons and a learning library. Everything is calculated in the browser (astronomy-engine, tropical zodiac, true node).

## Develop

```bash
npm install
npm run dev
```

`npm test` runs a sanity check against a known reference chart.

## Deploy to GitHub Pages

```bash
npm run deploy
```

Builds the app and pushes `dist/` to the `gh-pages` branch.
